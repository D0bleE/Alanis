# Sorpresa 11:11 para Alanis 💗

La sorpresa del huevo usa una animación CSS de cáscara que se agrieta y se abre; la foto real aparece después. No hay un pollito de caricatura.\n\n## Personalizar
1. Pon tu foto de niño en `imagenes/imagen1.jpg`.
2. Pon tres fotos de Alanis en `imagenes/imagen2.jpg`, `imagen3.jpg` e `imagen4.jpg`.
3. Pon el audio elegido en `musica/cancion.mp3`.
4. Abre `index.html` en tu navegador para probar.

## Publicar gratis con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `sorpresa-1111`.
2. Sube todos los archivos y carpetas de este proyecto (no solo el ZIP).
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera a que GitHub Pages publique la web. El enlace aparecerá en esa misma sección.

No subas fotos íntimas ni información privada. Recuerda que en un repositorio público las fotos y el audio serán accesibles para cualquiera que tenga el enlace.
